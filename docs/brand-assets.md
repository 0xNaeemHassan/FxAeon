# Brand asset provenance

FxAeon uses the official f(x) / FXN Protocol mark beside the product attribution
“Powered by f(x) Protocol”. The attribution is used in the app and supporting
brand surfaces; it is not a separate app landing page. The local copy is the `FXN.svg` artwork from
AladdinDAO’s maintained asset repository, reproduced without a redraw:

- Source repository: <https://github.com/AladdinDAO/aladdin-assets>
- Source file: <https://github.com/AladdinDAO/aladdin-assets/blob/main/images/branding/FXN.svg>
- Raw source: <https://raw.githubusercontent.com/AladdinDAO/aladdin-assets/main/images/branding/FXN.svg>
- Retrieved: 2026-09-07

The local web asset is [`apps/mini-app/public/brand/fx-official-mark.svg`](../apps/mini-app/public/brand/fx-official-mark.svg).
The surrounding pill and wordmark are FxAeon UI treatment; the f(x) artwork
itself remains the upstream mark.
